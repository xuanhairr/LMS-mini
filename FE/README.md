# Hệ thống Frontend LMS-mini (React + Vite)

Tài liệu chi tiết về dự án, cấu trúc và cách vận hành đã được quy hoạch theo chuẩn Agent Driven Development (ADD) tại thư mục gốc của dự án.

Vui lòng xem chi tiết tại:
- [Kiến trúc Frontend](../../docs/architecture.md)
- [Quy trình phát triển ADD](../../docs/agent_workflow.md)

Để chạy dự án, nên dùng file script khởi chạy ở gốc dự án:
```bash
.\run.bat
```
Hoặc tại thư mục `FE/` này, chạy:
```bash
npm run dev
```
