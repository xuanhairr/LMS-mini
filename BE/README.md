# Hệ thống Backend LMS-mini (NestJS)

Tài liệu gốc đã được chuyển sang cấu trúc Agent Driven Development (ADD) tại thư mục `docs/` ở gốc dự án.

Vui lòng tham khảo:
- [Kiến trúc Backend](../../docs/architecture.md)
- [Các tính năng chính](../../docs/features)
- [Quy trình phát triển](../../docs/agent_workflow.md)

Để khởi chạy backend, vui lòng chạy lệnh ở thư mục gốc của dự án:
```bash
.\run.bat
```
Hoặc chạy trực tiếp tại thư mục này:
```bash
npm run start:watch
```
